# 行业特定分析维度扩展规则

> Phase 0 识别行业后，Phase 1 采集时自动加载对应 section 的额外搜索点。
> 不在列表中的行业 → 不加载额外规则，走通用 6 Agent 维度。

---

## 互联网 / 软件 / SaaS

### 额外搜索点（加到 6 个 Agent 的对应维度）

**Agent 1（战略与业务）额外：**
- 网络效应类型（单边/双边/跨边）和强度
- 核心北极星指标（活跃用户/留存/LTV/CAC...）
- 增长黑客手段 vs 品牌投放的比例
- 用户增长是自然/裂变/买量驱动

**Agent 2（决策与转折）额外：**
- 产品迭代节奏（发布频率、MVP 文化）
- 是否有"先做再看"的文化证据

**Agent 3（组织与人才）额外：**
- 工程师/PM/设计师的比例
- 技术栈选择倾向（新/旧/稳定）
- 远程办公/分布式团队程度

**Agent 5（他者视角）额外：**
- 数据安全/隐私争议
- 用户集中度风险

## 制造业 / 硬件

### 额外搜索点

**Agent 1（战略与业务）额外：**
- 供应链结构（纵向整合/外包/混合）
- 关键原材料依赖（价格波动风险）
- 产能利用率和扩张节奏
- 自动化程度 vs 劳动力成本

**Agent 2（决策与转折）额外：**
- 产能扩张决策的时机和逻辑
- 技术路线选择（自有/外购/合作）

**Agent 3（组织与人才）额外：**
- 蓝领/白领比例
- 工会关系
- 质量文化

**Agent 5（他者视角）额外：**
- 环境/ESG 争议
- 供应链风险（单一来源/地缘政治）
- 产品质量/安全事故历史

---

## 金融 / 银行 / 保险

### 额外搜索点

**Agent 1（战略与业务）额外：**
- 业务条线（零售/对公/投行/资管...）的风险-收益结构
- 监管资本充足率要求和实际水平
- 关键合规牌照
- 利率/政策敏感度

**Agent 2（决策与转折）额外：**
- 风险管理框架（VaR/压力测试/...）
- 历史风险事件（坏账/合规处罚）

**Agent 3（组织与人才）额外：**
- 合规部门的权力和独立性
- 激励机制的短期 vs 长期平衡（防止冒险文化）

**Agent 5（他者视角）额外：**
- 监管处罚历史
- 信用评级变化
- 系统性风险关联度

**Phase 2 额外提醒**：金融企业的决策心智模型**必然包含合规约束**——不要忽略这个维度。"监管红线"可能就是最重要的反模式。

## 消费 / 零售 / 品牌

### 额外搜索点

**Agent 1（战略与业务）额外：**
- 渠道结构（线上/线下/直营/加盟）
- SKU 管理（聚焦/分散/长尾）
- 定价策略（溢价/平价/渗透）
- 复购率/品牌忠诚度数据

**Agent 2（决策与转折）额外：**
- 品牌重塑决策的时机和逻辑
- 渠道转型（如线下转线上）的方式

**Agent 3（组织与人才）额外：**
- 门店/一线员工培训体系
- 供应链团队 vs 品牌团队的权力平衡

**Agent 5（他者视角）额外：**
- 供应链伦理争议（劳工/环保）
- 产品质量/安全事件
- 消费者投诉/维权历史

---

## 医药 / 医疗

### 额外搜索点

**Agent 1（战略与业务）额外：**
- 管线结构（自研/并购/合作）
- 研发投入占比
- 核心产品的专利到期风险
- 适应症覆盖策略
- BD（商务拓展）活跃度

**Agent 2（决策与转折）额外：**
- 研发管线取舍（砍哪个/保哪个）的决策逻辑
- 临床试验策略（快速跟进/首创新药）
- 并购决策的时机和整合能力

**Agent 3（组织与人才）额外：**
- 科学家/研发团队的地位
- 学术合作网络（CRO/学术机构）

**Agent 5（他者视角）额外：**
- 药品安全/不良反应事件
- 定价争议（高药价/医保谈判）
- 临床试验伦理争议

## 能源 / 资源

### 额外搜索点

**Agent 1（战略与业务）额外：**
- 资源储备规模和勘探节奏
- 低碳转型策略（化石→新能源）
- 地缘政治风险暴露
- 大宗商品价格敏感度

**Agent 5（他者视角）额外：**
- 环境破坏/排放争议
- 政策/监管变化风险
- 社会 license to operate

## Phase 2 行业适配提醒（重要）

某些行业的"心智模型"必然包含行业特有的约束，提炼时**不要忽略**：

| 行业 | 必须包含的约束维度 | 为什么 |
|------|------------------|--------|
| 金融 | 合规/监管红线 | 不了解监管约束就无法理解任何决策 |
| 医药 | 研发确定性/监管审批周期 | 研发管线取舍的决策完全取决于这些参数 |
| 能源 | 地缘政治/ESG | 这两个因素决定了能源企业的生存边界 |
| 互联网 | 网络效应/数据安全 | 护城河和风险的核心来源 |
| 制造业 | 供应链韧性/自动化程度 | 成本结构和竞争优势的核心 |
| 消费 | 品牌忠诚度/渠道权力 | 收入模式的基础 |

**通用检查**：Phase 2 提炼完成后，自检——这家企业所在行业的**核心约束维度**，在你的心智模型或启发式中出现了吗？如果没出现，可能遗漏了关键维度。
