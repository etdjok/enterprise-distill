# 企业思维框架提炼方法论

> 从企业公开信息到可运行的决策心智模型，核心方法论。
> 基于 huashu-nuwa 的三重验证法，适配企业场景。

---

## 一、企业心智模型识别的三重验证（企业版）

一个决策模式要被认定为「企业心智模型」而非「偶然行为」，必须通过三重验证：

### 验证1: 跨决策场景复现

同一个决策框架出现在企业**至少 2 个不同类型的决策场景**中。

| 决策场景类型 | 例子 |
|-------------|------|
| 产品决策 | 要不要做新功能 |
| 市场决策 | 要不要进新国家/渠道 |
| 组织决策 | 要不要新招 100 人 |
| 资本决策 | 要不要收购一家公司 |
| 危机决策 | 负面 PR 怎么处理 |

**好的例子**：亚马逊的"反传统定价"
- 在 Kindle/云服务定价中出现（定价不跟行业走，低到没人信）—— 产品决策
- 在 FBA 服务定价中出现 —— 市场决策
- 在 Prime 会员定价中出现 —— 战略定价决策
→ 跨 3 种决策场景复现 → 这是真心智模型

**坏的例子**：某企业"2018 年因为融资压力砍了营销预算"
- 只在那一个时间点出现
- 后来营销预算又加回来了
→ 不是心智模型，是偶然事件

### 验证2: 有生成力

用这个模型可以**推断企业面对新问题的可能反应**，而不只是描述过去的行为。

**好的例子**：如果字节的"字节范儿"是心智模型——
- 面对"要不要在游戏业务投入 XX 亿"→ 会问"有没有 PPT 还没写好就开始做的人？ROI 能不能在 6 个月内验证？"
- 面对"要不要开分公司"→ 会问"有没有本地团队已经在跑 MVP 了？"
→ 能生成新推断 → 是心智模型

**坏的例子**："这家企业喜欢招名校毕业生"
- 能描述过去的招聘行为，但不能推断面对"一个非名校但有 5 年经验的候选人"会怎么决策
→ 只是观察结论，不是心智模型

### 验证3: 有排他性

不是所有行业玩家都这样想，这个框架体现了**这家企业的独特决策风格**。

| 排他性程度 | 判断标准 | 例子 |
|-----------|---------|------|
| ✅ 高排他性 | 行业里只有这家/少数几家这样想 | 亚马逊的"飞轮优先于利润" |
| ⚠️ 中等排他性 | 行业里有几家这样想，但不是主流 | 华为的"以客户为中心"（听起来通用，但落地方式独特） |
| ❌ 低排他性 | 行业里大家都这样想 | "我们重视人才"（谁不这么说） |

**如果一个决策模式只通过了 1 重验证** → 降级为「决策启发式」而非「心智模型」
**如果一个决策模式 0 重验证都没过** → 只是偶然行为，不纳入

## 二、企业文化代码的三层深挖

从 Agent 3（组织与人才）+ Agent 4（表达与品牌）调研结果中提炼。

### Schein 三层结构

```
 Layer 1 · 表面层（可观察）
 ├── 物理环境：办公空间、着装、休息区
 ├── 仪式：新员工培训、年会、评审
 ├── 公开行为：会议形式、沟通风格
 └── 内部黑话：特定术语、流行语、缩写
 
 Layer 2 · 声称价值（官方宣称）
 ├── Mission/Vision/Value 声明
 ├── 官网/年报中的叙事
 ├── CEO 公开讲话中的核心价值观
 └── 员工手册中的行为准则
 
 Layer 3 · 基本假设（隐含信念）
 ├── 隐含的做事假设："我们相信 X，所以我们做 Y"
 ├── 权力距离假设："信息应该向上集中 / 向下扩散"
 ├── 人性假设："人需要被管 / 人想自己成长"
 ├── 成功假设："成功来自战略正确 / 成功来自执行到位"
 └── 风险假设："我们应该保守 / 我们应该激进"
```

### 三层深挖的操作步骤

1. **先列表面表层**：从 Glassdoor 评价、公司视频、员工分享中收集可观察的事实
2. **再收集声称价值**：从官网、年报、公开讲话中提取官方宣称的价值观
3. **找 gap**：表面层的行为和声称价值有矛盾吗？矛盾在哪里？
4. **深挖基本假设**：从"矛盾点"反推——这家企业真正相信什么，才会出现这个 gap？

### Gap 分析的例子

| 声称价值 | 实际行为 | 反推基本假设 |
|---------|---------|------------|
| "我们是扁平组织" | 决策必须经过 5 个层级审批 | 基本假设是"控制 > 效率"，"信任 > 授权"是假的 |
| "鼓励失败" | 失败的项目负责人被降薪 | 基本假设是"失败不可接受"，"学习"是公关话术 |
| "以客户为中心" | 客户数据用于内部 OKR 而不是产品改进 | 基本假设是"内部效率 > 客户价值" |

## 四、矛盾处理原则

继承 huashu-nuwa 的矛盾处理原则，企业版有额外的维度：

### 企业特有的矛盾类型

1. **声称 vs 实际**（企业版最常见）
   - 官方叙事："我们以客户为中心"
   - 实际行为：内部流程优先而非客户需求优先
   - 处理：**完整呈现矛盾**，标注为"核心张力"，深挖背后的基本假设

2. **业务层 vs 组织层**
   - 业务需要快速迭代
   - 组织流程要求层层审批
   - 处理：分业务线/部门记录冲突，不强求统一

3. **演化中的新旧模式**
   - 旧模式是 A，新模式是 B，当前处于过渡态
   - 处理：标注演化轨迹，说明"企业正在从 A 转向 B，但两者同时存在"

4. **创始人风格 vs 组织惯性**
   - 创始人喜欢冒险，组织已经僵化
   - 处理：记录这种张力，可能是下一次变革的驱动力

### 错误的处理方式

- ❌ 选一边忽略另一边
- ❌ 编一个调和的解释（"企业只是暂时这样"）
- ❌ 假装矛盾不存在
- ❌ 站边批评（"这家企业很虚伪"——分析不是吐槽）

## 五、信息不足时的处理

| 情况 | 处理 |
|------|------|
| 内部决策逻辑无法从公开渠道还原 | 诚实标注「这一层信息来自公开财报，内部真实决策逻辑可能不同」 |
| 只有二手信息 | 降低置信度，标注为「据 [来源] 报道，未经企业官方确认」 |
| 信息相互矛盾且无法判断 | 并列呈现，让用户自行判断。矛盾本身就是有价值的信息 |
| 企业刻意不公开某方面（如内部薪酬） | 尊重边界，注明「此维度为企业敏感信息，公开渠道有限」 |
| 某行业特有信息（如药品研发数据、金融风控模型） | 承认局限，说明「监管不要求公开，此维度分析基于行业惯例推断」 |

## 六、企业 Skill vs 人物 Skill 的区别

| 维度 | 人物 Skill (huashu-nuwa) | 企业 Skill (本 Skill) |
|------|-------------------------|----------------------|
| 核心分析对象 | 一个人的思维方式 | 一个组织的决策逻辑 |
| 心智模型来源 | 主要来自一个人 | 来自多场景决策的综合 |
| 三重验证适配 | 跨话题复现 | **跨决策场景复现** |
| 表达分析 | 个人表达 DNA | **组织叙事策略和语言风格** |
| 矛盾处理 | 个人内在矛盾 | **声称 vs 实际、业务 vs 组织、新旧模式** |
| 诚实边界 | "我不是这个人" | **"公开信息 ≠ 真实决策逻辑"（更重）** |
| Agent 维度 | 著作-对话-表达-他者-决策-时间线 | **战略-决策-组织-表达-他者-时间线** |
| 输出角色扮演 | "我是 XX" | "我用 XX 企业的决策框架帮你分析" |

## 七、质量自检清单（企业版）

生成 Skill/画像后，逐项自检：

### 心智模型
- [ ] 每个模型都有 ≥ 2 个**不同决策场景**的证据？（跨域复现）
- [ ] 模型数量在 3-7 个之间？（太少=没提炼，太多=没聚焦）
- [ ] 每个模型都有明确的应用场景和**局限性**？
- [ ] 删掉企业名字后，还能认出这是**哪家企业**的决策方式？（排他性）

### 决策启发式
- [ ] 每条规则都有**具体决策案例**支撑？
- [ ] 可以被新情况触发（不只适用于原始案例）？

### 反模式与禁忌
- [ ] 至少 2 条这家企业**明确反对/踩过坑**的做法？
- [ ] 不是"通用商业道理"（如"我们反对贪污"谁都反对）？

### 文化代码
- [ ] 三层（表面/声称/基本假设）是否都有分析？
- [ ] Gap 分析是否识别了声称 vs 实际 的矛盾？
- [ ] 基本假设是从 gap **反推**出来的，还是编造的？

### 商业模式
- [ ] 收入来源按业务板块拆解，有具体占比？
- [ ] 护城河不是只说"有品牌"这种空话，而是说清楚**在哪一层、为什么**？

### 诚实边界
- [ ] 明确写了**"公开信息 ≠ 真实决策逻辑"**？
- [ ] 标注了信息源和调研时间？
- [ ] 承认了**至少一个维度**的信息不足？

### 整体
- [ ] 用这个框架分析一个新问题，能得到**有价值的独特视角**（不是通用 AI 腔）？
- [ ] 同时分析两家相似企业，输出有**实质差异**（不是换皮）？
- [ ] 至少识别了 **1-2 个核心张力**（没有矛盾 = 分析不深）？
- [ ] 没有编造/美化/站边（描述 vs 判断 vs 立场分离）？
