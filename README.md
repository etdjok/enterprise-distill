# Enterprise Distill · 企业蒸馏 Skill

> 「分析企业不是收集财报，而是让它的思维方式在你的头脑中重新生长。」

一个 Trae Skill（AI Agent 技能），把一家企业**蒸馏为可复用的思维框架**：捕捉的不是这家企业"做什么"（WHAT），而是它"怎么想、怎么判断、怎么决策"（HOW）。

本 Skill 不是企业画像的搬运工，而是**企业思维的提炼者**——产出可以直接"运行"、能用来推断新问题立场的思维操作系统。

---

## 它解决什么问题

传统企业分析框架（波特五力、资源基础观、麦肯锡 7S 等）给出的是**静态结构快照**——告诉你"这家企业有什么特点"。

本 Skill 在此基础上更进一步，产出**可运行的思维框架**——让 AI 以"这家企业的决策逻辑"来思考你的问题，能推断它对**没经历过的新问题**会怎么站队。

| 维度 | 传统框架（五力 / RBV / 7S） | 本 Skill |
|------|------------------------------|----------|
| 输出 | 静态结构快照 | 可运行思维框架 |
| 告诉你 | "这家企业有什么特点" | "用这家企业的眼睛看你的问题" |
| 分析视角 | 外部观察者 | 内部决策逻辑 |
| 可运行性 | 不可（只是描述） | 可（能推断新问题） |

## 三种使用模式

| 模式 | 触发示例 | 产出 |
|------|---------|------|
| **A · 企业画像** | "帮我分析一下 XX 的底层逻辑" | 结构化深度分析报告 |
| **B · 企业 Skill** | "蒸馏 XX，做个 XX 视角的 Skill" | 可运行的 `SKILL.md` 思维顾问 |
| **C · 跨企业对比** | "对比 A 和 B 的战略哲学" | 多家画像 + 概念网络 + 对比矩阵 |

## 执行流程（Phase 0 → 6）

```
Phase 0   入口分流与需求确认（模式判定 + 档位 + 信息源模式）
Phase 0.5 创建 Skill 目录结构 + 加载行业适配器
Phase 1   多 Agent 并行采集（6 个企业分析维度）
Phase 1.5 调研质量检查点 🔴
Phase 2   三层提炼（战略逻辑 → 组织基因 → 决策模式）
Phase 2.5 提炼质量检查点 🔴
Phase 3   构建产出（模式 A / B / C）
Phase 4   质量验证（独立子 Agent 测试）
Phase 5   跨企业概念网络（可选，模式 C）
Phase 6   保真度评分（可选）
```

核心创新是 Phase 1 的 **6 个 Agent 维度**（战略与业务 / 决策与转折 / 组织与人才 / 表达与品牌 / 他者视角 / 时间线），以及 Phase 2 的**企业版三重验证法**（跨决策场景复现、有生成力、有排他性）。

## 快速使用

1. 在 Trae 中将该目录作为 Skill 上传/加载（`SKILL.md` 含 `name` + `description` 的 YAML frontmatter）。
2. 用触发词调用，例如：
   - "用 **企业蒸馏** 分析一下字节的底层逻辑"（模式 A）
   - "蒸馏亚马逊，做个**亚马逊视角的 Skill**"（模式 B）
   - "对比**阿里和京东**的战略哲学"（模式 C）

为避免知识产权纠纷，本项目**如实列出所借鉴的外部模型、方法论与已有 Skill**。本 Skill 本身是这些方法的**适配与再组合**，并非原始方法的发明者；相关原始方法的著作权仍归原作者所有。

### 一、借鉴的外部分析方法 / 理论模型

本 Skill 在"三层提炼"、护城河分析、文化深挖、行业定位等环节，直接调用了以下公开的商业/管理分析模型（均为学术界与业界广泛通用的概念）：

| 模型 / 理论 | 提出者 / 来源 | 在本 Skill 中的用途 |
|------------|--------------|--------------------|
| 波特五力（Porter's Five Forces） | Michael E. Porter | Layer 1 行业位置分析（识别当前竞争位置与竞争对手差异化） |
| VRIN 框架（资源基础观 RBV） | Jay Barney（资源基础理论） | Layer 1 护城河地图（区分哪些资源是真 VRIN、护城河在哪一层） |
| 麦肯锡 7S（McKinsey 7S） | Tom Peters / Robert Waterman（McKinsey & Company） | 对照框架：识别"静态结构快照"盲区，并作为组织基因的分析参照 |
| 文化三层模型（Culture Model） | Edgar Schein | Layer 2 组织基因"文化代码"深挖（表面层 / 声称价值 / 基本假设） |
| 动态能力理论（Dynamic Capabilities） | David Teece 等 | 对照框架：用于理解企业"演化/拐点"维度 |
| BCG 矩阵（波士顿矩阵） | Boston Consulting Group | 业务组合的协同/冲突与增长引擎分析（模式 A 商业模式图） |
| 价值链分析（Value Chain） | Michael E. Porter | Agent 1"收入来源按板块拆解"的参考 |

> 说明：上述模型的名称与思想属各自原作者/机构。本 Skill 仅在分析流程中**调用这些成熟模型作为工具**，不主张对其所有权。

## 局限性（诚实边界）

- 本 Skill 基于**公开信息**提炼，"公开信息 ≠ 真实内部决策逻辑"，结论应视为框架推断而非企业官方立场。
- 蒸馏非公众企业需由用户提供内部素材，涉及隐私与本人意愿。
- 信息源黑名单：知乎、微信公众号、百度百科（洗稿/失真/无法验证）。
